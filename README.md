# SDRC Infrastructure

SDRC's infrastructure automation and disaster recovery toolkit.

## Supported systems

- VPS1
- VPS2
- Future Nextcloud and Collabora services
- Local Mirth
- DEXA
- Orthanc

## Roadmap

The first milestone is encrypted backups to Hostinger FTP.

Future milestones include restore automation, infrastructure inventory, monitoring, and CTO dashboard integration.

## Repository structure

- `backup/` — backup documentation, configuration, libraries, and logs
- `docs/` — project documentation
- `inventory/` — infrastructure inventory
- `monitoring/` — monitoring resources
- `scripts/` — operational scripts
